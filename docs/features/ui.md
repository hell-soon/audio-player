# Каркас, навигация и анимации

Подробности к `AGENTS.md` (общие правила проекта — там). Нижнее меню, «парящий» плеер, загрузочный экран, анимации страниц и списков, v-reveal, шапка коллекции, предзагрузка по намерению, горячие клавиши, настройки.

- Скелетоны вместо спиннеров: `UiSkeleton`, `UiSkeletonRows`, `CollectionSkeleton` (раскладка совпадает со страницей). «Нет соединения» — `widgets/network-status`. Сгенерированные обложки — `PlaylistCover :name` (цвет от названия). Быстрые действия иконки — `shortcuts` в `public/manifest.webmanifest` (`/?start=wave` запускает волну; на iOS shortcuts не поддерживаются).
- **Телефон: плеер и меню «парят» над страницей** (`.shell__bottom` — `position: absolute` внизу каркаса, `pointer-events` только у плеера и меню): страница прокручивается под ними, меню — полупрозрачное стекло. Отступ снизу у содержимого — `--bottom-h` (ResizeObserver в `layouts/default.vue`).
- **Главная** — приглушённый фон из обложки и акцентная «Моя волна». «Собрано для вас» показывает список с небольшими обложками, нейтральные плитки «Миксы по годам» стоят справа на широком экране и под списком на узком.
- **Нижнее меню** (`MobileNav`): пункты — Главная, Поиск, Библиотека, Друзья, **Профиль** (значок, без фото); настройки открываются шестерёнкой в шапке профиля, на `/settings` и `/link` подсвечен «Профиль». На компьютере в боковой панели внизу — и профиль, и настройки. `/settings#privacy` прокручивает к разделу приватности (кнопка «Приватность» в профиле). Плавающая капсула, одна подсветка `__indicator` переезжает к разделу; раздел отмечается сразу по `pointerdown` (`pending`), не дожидаясь открытия страницы. Подсветку можно тащить пальцем (как в Telegram): удержание 200 мс или сдвиг > 8 px. Касания меню целиком наши (touch-события, `preventDefault` на `touchstart`, тап тоже обрабатываем сами) — иначе iOS при удержании ссылки начинает её перетаскивание и обрывает жест. Позиция — свойство **`translate`, не `transform`** (transform применяется после `scale` приподнятой подсветки — сдвиг тоже масштабировался, и она обгоняла палец), пишется в style раз за кадр (rAF) без CSS-переходов. **Переходы страниц на телефоне — без View Transition** (`plugins/page-transition.client.ts` ставит `meta.viewTransition = false`): VT замораживает экран до готовности страницы, меню «провисало»; вместо него — CSS `page-enter` у `.shell__content`. **Прокрутка** — у `.shell__main`, роутер её не трогает: сброс/восстановление «назад» — в `layouts/default.vue`.
- **Загрузочный экран** (`src/app/ui/AppSplash.vue`, в `app.vue`): приходит в HTML с сервера, уходит после гидрации (не раньше 0,5 с от начала загрузки); без JS CSS убирает его через 6 с.
- **Анимации** (`shared/styles/_motion.scss`, всё гасится при «уменьшить движение»): переход страниц — двигается только `.shell__main` (`view-transition-name: page`), направление вперёд/назад ставит `plugins/page-transition.client.ts` в `html[data-vt]` (без атрибута — другие переходы, например перелёт обложки, не трогаются); строки списков — `rise-in` лесенкой по `--i`; `UiSegmented` — «пилюля» едет к выбранному; `UiDialog` — `@starting-style` + `allow-discrete`; обложки `UiCover` проявляются после загрузки (только загруженные на клиенте). Анимировать `transform`/`opacity`, не `width`/`top` (прогресс мини-плеера — `scaleX`). Значок в `UiIconButton` — 55 % от родителя: обёртка вокруг значка должна быть на всю кнопку.
- **Анимация списков (`TransitionGroup`)**: ключи — `stableKeys` из `@/shared/lib` (uid, повтор — `uid#n`), **не** `uid-index` (иначе при удалении все строки ниже пересоздаются); уходящую строку снимает с потока `pinLeaving` (в grid у абсолютного элемента без координат место — угол контейнера), контейнеру — `position: relative`. `TrackList` анимирует только точечные изменения (≤ 8 строк: удаление, новый лайк); поиск по списку и смена коллекции — без анимации (`:css="false"`). У `li` анимация появления — `fill: backwards`: с `both` она держала transform и перебивала сдвиг (`*-move`). Очередь «Далее» в карточке — так же. Удаление из плейлиста убирает строки сразу (ошибка — возвращаем).
- **Шапка коллекции при прокрутке** (`CollectionView`): `view-timeline: --collection-head` у шапки, `timeline-scope` у `.collection`; обложка (параллакс + уменьшение) и текст гаснут, на `exit 70%–100%` проявляется компактная полоса (`__sticky` нулевой высоты; название — наверх, кнопка — играть/пауза). Без scroll-driven animations или при «уменьшить движение» полосы нет, шапка статична.
- **Предзагрузка по намерению** (`plugins/prefetch.client.ts`): касание/наведение на внутреннюю ссылку → `prefetchData` с теми же ключами, что у страниц (`dataFor(path)` — при новой странице с данными добавить её туда).
- **Плеер на компьютере «парит»** над страницей, как на телефоне: `.shell__bottom` в той же ячейке сетки, что `.shell__main` (`align-self: end`), отступ снизу у содержимого — `--bottom-h`.
- **Появление при прокрутке** — директива `v-reveal` из `@/shared/lib` (`reveal.ts`, стили `.reveal-*` в `_motion.scss`): что при монтировании ниже экрана — прячется, при первом появлении (IntersectionObserver, нижний край — над `--bottom-h`) проигрывает анимацию и дальше видно всегда; появившиеся в одном кадре — лесенкой; проскоченные — сразу, без анимации; что видно при открытии страницы — не трогается. Виды: `rise` (альбомы, `TrackCard`), `row` (строки `TrackList`), `tilt` (плейлисты — «конверт» встаёт с наклоном), `pop` (исполнители — фото «выпрыгивает», имя следом). **Не возвращать scroll-driven `animation-timeline: view()`**: таймлайн пересчитывается только при прокрутке — после сдвига раскладки без неё (догрузка данных при быстрой прокрутке) карточки и строки застревали полупрозрачными. Имена кадров директивы — с префиксом `reveal-` (по нему ловится конец своей анимации).
- Настройки на компьютере (`up(lg)`) — две колонки карточек; на телефоне колонки `display: contents`, порядок — `--o`.
- **Горячие клавиши** (`features/hotkeys`): буквы — по `e.code` (работают в русской раскладке); `HOTKEYS` — группы с сочетаниями в записи `mod+k`, `shift+right` (`mod` — ⌘ на Mac, Ctrl на остальных). Показ клавиш — `UiKbd combo="mod+k"`, в подсказках кнопок — `UiIconButton shortcut="…"` (дописывается в `title` после гидрации: Mac известен только в браузере).
