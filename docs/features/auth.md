# Вход и приветствие

Подробности к `AGENTS.md` (общие правила проекта — там). Вход с другого устройства, passkeys, /welcome, страница входа-лендинг.

- **Вход с другого устройства** (`login-link.ts`, `/api/auth/link/{start,poll,info,approve}`, `features/auth-by-code`, страница `/link`): новое устройство показывает 6 цифр и QR (`uqr`), вошедшее подтверждает; код живёт 3 мин, одноразовый; токен опроса — в базе sha-256.
- **Face ID / Touch ID** (passkeys, `nuxt-auth-utils` WebAuthn: `auth.webAuthn` в конфиге, `/api/webauthn/{register,authenticate}`, `features/auth-by-passkey`): ключи «запоминаемые» (`residentKey: required`) — вход без имени; вызовы хранятся в `webauthn_challenges` (не в памяти — разные инстансы Vercel). **WebAuthn не работает на IP** (127.0.0.1): проверять на `localhost` (прод-сборка) или на домене.
- **Приветствие** `/welcome` («Чем вы пользуетесь?» → подключить сервис): `users.onboarded` (новые — false, старые — true), в сессии `user.onboarded`; глобальный middleware ведёт туда, пока не пройдено.
- **Приветствие/вход** (`pages/login`): живой фон (пятна — radial-gradient без filter, «волна» эквалайзера), превью плеера, «Что умеет», подсказка установки PWA; вход — `features/auth-by-*`. Логотип — `UiLogo` (он же на загрузочном экране). Плеер (`plugins/player.client.ts`) запускается **только для вошедших** — иначе на странице входа опрос устройств сыпал 401.
- **Страница входа — лендинг** (`pages/login`): стеклянная панель сверху (якоря `scrollTo`), первый экран — заголовок + карточка входа (`#login`) с «парящими» мини-плеером и плашкой (только компьютер), бегущая строка, «бенто» возможностей (`v-reveal`, мини-иллюстрации на CSS), «Как начать», «Что понадобится», «Вопросы» (`<details>`), финальный призыв. Всё на токенах темы. Тексты про Spotify — честные: Premium для воспроизведения на компьютере, доступ добавляет владелец (до 5 человек). Страница прокручивается окном (не `.shell__main`): `overflow-x: clip`, а не hidden. Панель сверху — `position: fixed` (место в потоке держит `.nav-slot` высотой `--nav-top + --nav-h`), **не `sticky`**: в Safari на iPhone «прилипшая» панель при прокрутке окна дёргалась и уезжала со страницей у нижнего края (#1).
